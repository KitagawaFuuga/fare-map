# AI の誤りの記録

このリポジトリのコードは AI（Claude Code）が書いている。AI の書いた誤りを
何が止めたか、止められなかったものは何で見つかったかを残す。同じ種類の誤りが
続くなら、検査を足す根拠にする。

- 見つけたもの: フック（Probity）/ 単体テスト / E2E / CI / レビュー / 人の確認
- 時点: 「マージ前」か「すり抜け」（マージや公開の後に見つかった）
