# 0007: 計算で作る特定運賃を、距離の誤差を直したコードで作り直して同じ PR に入れる

- 日付: 2026-11-25
- 状態: 採用
- 決めた人: ユーザー

## 背景

PR #18 で、駅間キロを足す順番の誤差（15 が 15.000000000000002 になる）で運賃表の境目を越え、
1つ上の運賃帯を引く不具合を直した。`scripts/fare/ingest/compute-fares.ts` が作る
`data/fare-overrides/*-computed.json` も同じ計算で作られていて、作り直すと近鉄 55組・名鉄 1組の
運賃が下がる（10〜160円。例: ファミリー公園前→岡寺は 14.000000000000002km で「18km まで」の帯を引き
450円、表どおりなら 380円）。今の main のコードで作り直しても運賃は変わらないので、変わるのは修正の効果。

## 選択肢

- 案A: 作り直したデータを PR #18 に入れてからマージする。コードとデータの直しが1つにそろう。差分が大きくなる
- 案B: PR #18 はコードだけでマージし、データは別の PR にする。差分は分かれるが、その間は本番で高めの運賃が残る

## 決定

案A。高めに出る誤りは「予算内で行ける駅を行けないと表示する」側で、コードを直したのにデータだけ
古いままにする理由がない。

## 結果

近鉄・名鉄の計算で作る特定運賃 56組が、運賃表どおりの額になる（すべて下がる）。出典（公式の運賃規則）は
変わらない。meeting-station も同じデータを持つので、同じく作り直す。
