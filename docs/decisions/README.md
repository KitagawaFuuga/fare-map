# 設計判断の記録

選択肢が2つ以上あった決定を、1件1ファイルで残す。コードと git log からは
「何をしたか」は読めても「なぜ他の案にしなかったか」は読めないため。

ファイル名は `NNNN-短い英語の名前.md`。一度書いた記録は書き換えず、判断を
変えたときは新しい番号で書いて、古いほうの状態を「NNNN で置き換え」にする。

## 書式

```markdown
# NNNN: 決めたこと（1行）

- 日付: YYYY-MM-DD
- 状態: 採用 / NNNN で置き換え
- 決めた人: ユーザー / AI

## 背景

何に困っていたか。

## 選択肢

- 案A: 内容。良い点と悪い点
- 案B: 内容。良い点と悪い点

## 決定

選んだ案と理由。

## 結果

これで何が変わるか。引き受けた欠点。
```
