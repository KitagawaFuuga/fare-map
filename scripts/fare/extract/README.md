# 公式運賃表PDFからの抽出

各社の公式運賃表（多くは三角表のPDF）から全駅ペアの運賃を取り出すスクリプト。
出力は `data/fare-sources/<id>.json` の元になる生データで、そこから距離帯テーブル
(`data/fare-rules/`) と特定運賃 (`data/fare-overrides/`) を起こしている。

運賃改定のたびに同じ作業をやり直すことになるので、**行と列の座標グリッド・駅の並び・
テキスト層から拾えなかったセルの実測値**をスクリプトに残してある。これが無いと、
駅名が読めないPDFから行列の対応を推測し直すところからやり直しになる。

## 前提

```
pip install pymupdf
```

PDFはリポジトリに入れていない。各スクリプト冒頭のコメントと
`data/fare-sources/<id>.json` の `source.url` から取得して、任意のディレクトリに置く。

## 使い方

```
python scripts/fare/extract/<id>.py <PDFを置いたディレクトリ>
```

ディレクトリは環境変数 `FARE_PDF_DIR` でも指定できる。出力は同じディレクトリに書かれる。
結果を `data/fare-sources/<id>.json` の `pairs` に反映すると、
`lib/fare/__tests__/fare-sources.test.ts` が距離帯＋特定運賃での再現を検証する。

## このPDF群でつまずいた点

- **駅名が読めない**。フォント内蔵エンコードのため文字化けする。数値は座標付きで取れるので、
  セルを等間隔グリッドに割り当て、行と列の駅の並びはページを画像にして目視で確認した。
- **行が等間隔とは限らない**。富山地方鉄道の本線は、理論上の行位置のうち1行ぶんが列ヘッダに
  使われていて東三日市以降が1つ後ろにずれる。取り違えると荻生以降の運賃が1駅ぶんずれる
  （荻生→宇奈月温泉は740円だが、ずれると840円になる）。
- **列も等間隔とは限らない**。しなの鉄道は罫線の都合で列間隔が揺れるので、
  全列が埋まる最終行から列位置を実測している。
- **左端のセルが縦書きの線名ラベルと結合する**。`"???1680"` のような単語になるため、
  末尾の数値を取り出し、位置は単語の右端で揃える。
- **列ヘッダと重なるセルはテキスト層に出ない**。富山地方鉄道で15セル、えちぜん鉄道で
  1セル。画像を読んで `manual` リストに実測値を置いてある。
- **表が複数同居する**。えちぜん鉄道の運賃表PDFには定期運賃表も入っている。
  トークン順に頼らず、セル座標で三角表の領域だけを拾う。

## 抽出結果の検証

駅名が読めない以上、行列の対応づけを間違えても値としては「それらしく」出てしまう。
採用前に最低限この2つを確認すること。

1. **全ペアが公式の運賃額一覧に載る値であること**（定期運賃表の左列などから拾える）
2. **着駅を固定して発駅を1駅ずつ遠ざけたとき、運賃が下がらないこと**（各線の中で）

距離帯に落とすときは `lib/fare/derive.ts` の `deriveFareTable` が自己検証してくれる。
